## A little about me

I like starting with a real problem, building the smallest version that can help, and learning from what happens next. That process has taught me to think about the parts people actually feel: clear interfaces, honest limits, privacy, and whether the result is affordable and useful.

I use AI tools to research, compare ideas, write, and debug faster. I still review the work, understand the decisions, and keep the trade-offs visible.
